# Yatay Geçiş Takip Paneli

Bu proje, üniversite yatay geçiş süreçlerini takip etmek amacıyla React kullanılarak geliştirilmiş bir frontend web uygulamasıdır. 

## 🚀 Canlı Demo
Uygulamayı canlı olarak incelemek için tıklayın: **[Yatay Geçiş Takip Paneli](https://merry-snickerdoodle-9ea6ec.netlify.app)**

## 🛠️ Kullanılan Teknolojiler
* React
* HTML / CSS
* JavaScript

## 💻 Kurulum ve Çalıştırma

### Ön Gereksinimler
* Node.js (güncel sürüm)
* npm veya yarn

### Adımlar

1. Projeyi klonlayın:
git clone https://github.com/mustafakeskik/yatay-gecis-panosu.git

2. Proje klasörüne gidin:
cd yatay-gecis-panosu

3. Proje bağımlılıklarını yükleyin:
npm install

4. Geliştirme sunucusunu başlatın:
npm start
